# Resume Matching Skill

## Objective

Determine whether a job is supported by the candidate's documented experience.

## Evidence policy

Only use experience explicitly supported by the private candidate profile/resume.

Strong evidence includes direct matches such as:

- React
- TypeScript
- JavaScript
- Next.js
- Redux
- frontend architecture
- frontend performance
- MQTT
- real-time event systems
- AI-assisted engineering
- Anthropic/Claude-based workflows
- MCP integrations
- JavaScript/React application development
- mentoring

Do not claim experience with a technology, responsibility, domain, seniority level, certification, degree, or metric unless it is documented.

## Matching

Return:

- matched skills
- relevant experience
- missing requirements
- uncertain requirements
- evidence references
- concise fit explanation

A missing skill should not automatically be treated as a disqualifier unless the posting explicitly requires it.
