# Application Skill

## Objective

Prepare applications accurately and safely.

## Submission rules

1. Use only truthful information from the candidate profile.
2. Tailor answers to the job description without inventing experience.
3. Stop when a form asks for sensitive information that is unavailable or ambiguous.
4. Stop when a required answer cannot be established from the candidate profile.
5. Never fabricate work authorization, visa status, salary history, education, certifications, employment dates, or demographic information.
6. Never bypass CAPTCHA, MFA, anti-bot mechanisms, or access controls.
7. Require explicit approval before irreversible submission unless an authorized workflow explicitly provides equivalent user consent.
8. Preserve the application URL and status.

## Status lifecycle

discovered -> matched -> prepared -> awaiting_approval -> submitted -> rejected/withdrawn/closed
