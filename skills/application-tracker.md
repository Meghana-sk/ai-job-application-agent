# Application Tracker Skill

Track job opportunities without committing private candidate data to the public repository.

Recommended private record:

- job ID
- company
- role
- application URL
- discovered timestamp
- application status
- submitted timestamp
- notes

Never store:

- passwords
- session cookies
- authentication tokens
- payment information
- unnecessary personal information

The public repository should contain only schemas/examples, not the user's actual application history.
