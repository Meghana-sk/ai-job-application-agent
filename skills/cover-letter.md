# Cover Letter Skill

Create concise, job-specific material using only verified candidate evidence.

Prioritize relevant examples:

- ownership of checkout applications
- React/TypeScript frontend development
- document-scanner integrations
- real-time MQTT communication
- frontend performance and memory-leak work
- AI-assisted engineering workflows
- AI-driven on-call reporting
- mentoring
- e-commerce frontend architecture, SEO, SSR, accessibility, and performance

Do not:

- invent company-specific enthusiasm
- claim knowledge not documented
- repeat the entire resume
- create unsupported numerical achievements

The final copy should sound natural and specific to the role.
